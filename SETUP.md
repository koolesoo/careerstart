# Подключение общей раздачи карточек

1. В Supabase создайте проект.
2. В SQL Editor выполните содержимое `supabase.sql`.
3. В `supabase-config.js` укажите Project URL и публичный anon/publishable key из Project Settings → API Keys. Для текущего проекта файл уже заполнен.
4. Сайт публикуется из корня репозитория через GitHub Actions workflow в `.github/workflows/pages.yml`.

В браузер можно помещать только публичный anon/publishable key. Не добавляйте в сайт service-role key.

Организатор нажимает «Создать новую сессию» и делится кодом или ссылкой. Участники входят по этому коду, выбирают одну из трёх команд и получают карточку. Выдача атомарная: в одной команде одной сессии одна карточка не выпадет дважды. В каждой новой сессии раздача начинается заново. Старые сессии сохраняются в Supabase; повторное создание сессии не сбрасывает предыдущую.
