# Собери команду

Готовая мобильная игра для занятия о старте карьеры. В проект входят страница игры, изображения, конфигурация Supabase и SQL-схема.

## Загрузить в GitHub Pages

1. Распакуйте архив на компьютере.
2. Откройте репозиторий `koolesoo/careerstart` на GitHub и нажмите **Add file → Upload files**.
3. Откройте распакованную папку и перетащите в окно GitHub все файлы из неё, включая изображения, `supabase-config.js`, `supabase.sql` и `index.html`. Не загружайте сам ZIP-архив.
4. Нажмите **Commit changes** и сохраните изменения в ветку `main`.
5. В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
6. Через несколько минут сайт будет доступен по адресу https://koolesoo.github.io/careerstart/

Настройка общей раздачи карточек описана в `SETUP.md`. Файл `supabase-config.js` содержит только публичный ключ Supabase, предназначенный для браузера. Не добавляйте в него service-role key.
